
# CCNA Labs | Cisco Networking

A collection of hands-on networking labs completed using Cisco Packet Tracer while studying for the **Cisco CCNA certification**. This repository documents my progress in routing, switching, network security, and troubleshooting.

## 🛠️ Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 & IPv6
- VLANs & Trunking
- STP & EtherChannel
- Static Routing & OSPF
- DHCP & DHCP Snooping
- ACLs & Network Security
- Port Security & Dynamic ARP Inspection (DAI)

## 📚 Lab Topics

| Topic | What I'm Practicing |
|---|---|
| Networking Fundamentals | OSI model, Ethernet, MAC addresses, ARP |
| IPv4 & IPv6 | Addressing and subnetting |
| Switching | MAC address tables and interface configuration |
| VLANs & Trunking | VLAN creation, access ports, trunk ports |
| STP | Spanning Tree Protocol and loop prevention |
| Routing | Static routes, default routes, OSPF |
| DHCP | DHCP configuration and DHCP Snooping |
| Network Security | ACLs, DAI, port security, VLAN hopping prevention |
| Troubleshooting | Connectivity testing and IOS verification commands |

## 📁 Repository Contents

Each lab will include relevant Packet Tracer files (`.pkt`), CLI configurations, screenshots, and notes explaining the commands and verification results.

## 🎯 Goal

Build practical networking skills, strengthen my understanding of Cisco IOS, and develop a portfolio of hands-on labs for future IT support and network engineering opportunities.
