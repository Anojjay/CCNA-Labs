# IPv6 EUI-64 & Static Routing Lab

Configured IPv6 addresses on R1 and R2 using EUI-64, enabled IPv6 routing, and assigned IPv6 addresses and default gateways to PC1 and PC2. Configured IPv6 static routes on both routers to allow communication between different networks.

Verified the IPv6 interface configurations and successfully tested end-to-end connectivity between PC1 and PC2 using ping.

**Key Concepts:** IPv6 addressing, EUI-64, link-local addresses, IPv6 static routes, default gateways, IPv6 routing.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
