# NTP Configuration Lab

Configured the software clocks and time zones on R1, R2, and R3. Configured R1 to synchronize with an external NTP server (1.1.1.1) and act as an NTP stratum 8 master for R2 and R3.

Enabled NTP authentication using an MD5 key and configured R2 and R3 to synchronize with R1. Configured NTP calendar updates and verified synchronization using NTP status and association commands.

**Key Concepts:** NTP, time synchronization, stratum levels, NTP master, NTP authentication, MD5, time zones.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
