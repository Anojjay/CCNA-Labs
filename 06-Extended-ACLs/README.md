# Extended ACLs Lab

Configured extended ACLs on a Cisco router to control traffic based on source IP, destination IP, and protocol/port numbers. Blocked DNS requests from the 172.16.1.0/24 network to SRV1, restricted traffic from 172.16.2.0/24 to PC1, and blocked HTTP/HTTPS access to SRV2.

Verified the ACL rules using ping tests, DNS resolution tests, and HTTP/HTTPS browser tests while allowing other traffic.

**Key Concepts:** Extended ACLs, wildcard masks, TCP/UDP filtering, DNS, HTTP/HTTPS, traffic filtering, inbound ACLs.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
