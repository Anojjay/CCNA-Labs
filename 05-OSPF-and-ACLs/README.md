# OSPF & Access Control Lists (ACLs) Lab

Configured OSPF on R1 and R2 to establish neighbor relationships and enable communication between networks. Implemented standard numbered ACLs on R1 and standard named ACLs on R2 to control which PCs could access specific networks and servers.

Verified routing tables, OSPF neighbor adjacency, and ACL behavior by testing permitted and denied connectivity using ping.

**Key Concepts:** OSPF, standard numbered ACLs, standard named ACLs, wildcard masks, traffic filtering, interface ACLs, network security.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
