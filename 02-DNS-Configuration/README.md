# DNS Configuration Lab

Configured R1 with a default route to the internet and set up DNS using server `1.1.1.1`. Configured PC1, PC2, and PC3 to use the DNS server, then added static host entries on R1 for the PCs. Tested name resolution by pinging PC1 by hostname and `youtube.com`.

Used Packet Tracer Simulation Mode to examine DNS queries, DNS responses, and related network messages.

**Key Concepts:** DNS, hostname resolution, default routes, static host entries, ICMP, packet analysis.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
