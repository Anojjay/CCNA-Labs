# SSH Configuration Lab

Configured a Cisco switch (SW2) for secure remote management using SSH. Set the hostname, enable secret, local username authentication, and management IP address on VLAN 1. Configured the domain name, generated 2048-bit RSA keys, and restricted remote access to SSH only.

Applied an access control list to allow SSH connections only from PC1 and configured a 5-minute console and remote session timeout.

**Key Concepts:** SSH, RSA keys, local authentication, ACLs, VTY lines, management VLAN, session timeouts.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
