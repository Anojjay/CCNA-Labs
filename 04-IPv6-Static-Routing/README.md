# IPv6 Static Routing Lab

Configured IPv6 routing on three Cisco routers (R1, R2, and R3) and used SLAAC to automatically assign IPv6 addresses to PCs. Configured primary and backup static routes to enable communication between different networks.

Tested connectivity using ping and traceroute, then disconnected the primary R1–R3 link to verify that traffic successfully rerouted through R2.

**Key Concepts:** IPv6, SLAAC, static routing, floating static routes, link-local addresses, route redundancy, ping, traceroute.

**Tools:** Cisco Packet Tracer, Cisco IOS CLI
